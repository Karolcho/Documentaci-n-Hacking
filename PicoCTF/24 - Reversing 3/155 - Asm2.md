# Descripción
What does asm2(0x8,0x2e) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/e52eb78a50fe37d5d90fa3200de17edb7b6e51a3e01c583cec0ed94d9e9bc306/test.S)
# Solución
Analizar el archivo de ensamblador para comprender cómo interactúan los argumentos de la función dentro de un ciclo y calcular el valor final para tener la flag.

- Primero revisamos el código fuente. Notamos que aquí se crea un ciclo `while`. El código almacena nuestros argumentos en dos variables locales: una inicia en `0x2e` y la otra en `0x8`. El ciclo funciona sumándole `0xed` a la variable de `0x8` hasta que supere el límite de `0xe6da`. Al mismo tiempo, le suma `0x1` a la variable de `0x2e` en cada vuelta.
- Haciendo la matemática (o replicando el script en un lenguaje como Python o C), determinamos que el ciclo tiene que dar 250 vueltas (0xfa en hexadecimal) antes de romperse. Si a nuestra variable base `0x2e` le sumamos esas `0xfa` vueltas obtenemos `0x128`. Ese es el valor de retorno que colocamos para conseguir la flag.

0x128 _(Nota: lo dejo sin el `picoCTF{}` porque el reto especifica que no lleva el formato normal)._
